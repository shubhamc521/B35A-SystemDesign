# Design Patterns

- Its Reuseable Solutions

- Its resuseable solution to common software design problems.

- Describes ways to structure code, classes, and object interaction.


# Types of Design Patterns

1. Creational - Talks about creation of object
- When to create the object (Lazy vs Eager)
- How many instances to create (one or many)
- Which type to create (based on runtime conditions)

- Five Design Patterns solves different problems:

SINGLETON = One
Factory = Crreate based on type
Abstract Factory = Create Family
Builder = Build complex
Prototype = Clone

2. Structural - Talks about HOW to compose objects and classes
- How Object/classes are organized
- How to form the relationship between them.
- How to create larger structures from Smaller parts.

3. Behavioral - Talks about how objects communicate with each other
- How objects interact and collaborate
- How object will behave in different state.

Types:

Creational - Control HOW objects are created. (Object Creation)
Structural - Control HOW objects are organized. (Structured)
Behavioral - Control HOW objects communicate(behave) with each other.
